# 界面原型 · Layout 1 双栏控制台(定稿)

> 资产 for ticket 06 · 2026-07-16
> 经两版可交互 mockup 对比(Layout 2 对话流 vs Layout 1 双栏控制台),**采用 Layout 1**。原型在会话中以能点的 mockup 渲染验证过。

## 结构

- **顶栏**:应用名 `image-create` + 「生成 / 图库」tab + 累计用量 chip(本月 $ · 张数)+ 设置入口。
- **左栏(控制台)**:Mode 分段(文生图 / 参考图)→ Model 选择器 → 能力提示(随模型)→ 提示词 textarea → 参考图上传(**仅参考图模式显示**,dashed 拖入区,标「最多 N 张」)→ **动态参数面板** → 分隔线 → 单次成本预估「≈ $」→ 生成按钮(整宽,accent)。
- **右栏(预览)**:大图预览区 + 本批结果缩略条(选中态描边)+ 结果元信息(模型 · 尺寸 · 质量 · 耗时 · 实际 $)+ 结果操作(下载 / 重生 / 存模板 / 删除)。
- **图库**:顶栏 tab 切到独立视图(缩略网格,按 provider / model / mode / 时间过滤;详情 = 原图 + 完整参数 + 用量 + 操作)。

## 动态参数面板(核心,吃 03 的 `capabilities`)

- 选 **OpenAI** 模型 → `尺寸`(像素枚举)+ `质量`(low/medium/high)+ `数量 n`。
- 选 **Gemini** 模型 → `宽高比` + `分辨率`(0.5K–4K),n 灰为「一次 1 张」。
- 能力提示、参考图上限、成本预估都随所选模型的 `capabilities` / `pricing` 同步重渲染。

→ 原型验证了 03 抽象的关键论断:**一份 `capabilities`/`pricing` 元数据即可驱动整个参数面板 + 前置校验 + 成本预估**,无需为每家写死 UI。

## 其它元素落位

- **Prompt Template / 收藏**:提示词框旁入口(插入模板 / 存当前 prompt 为模板 / 收藏)。
- **成本**:左栏生成前「≈ $」预估;右栏结果显示实际 $;图库 / Usage 页看累计(见 07)。
