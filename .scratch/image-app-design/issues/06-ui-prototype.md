# 主界面与图库 UX 原型

Type: prototype
Status: resolved
Blocked by: 03

## Question

用 `/prototype` 做一个可反应的粗原型(mockup / stub 即可,一次性),回答「主界面长什么样、怎么用」:

- **生成主界面**:提示词输入、模式切换(文生图 / 参考图)、模型选择器、参数面板(随所选模型动态变化)、参考图上传、生成按钮、结果展示、加载 / 延迟状态。
- **图库 / 历史**:已生成结果的浏览、回看、重生、删除。
- **提示词模板 / 收藏**在界面上的位置。
- **成本 / 用量**在界面上如何呈现(与「成本估算」ticket 呼应)。

依赖「提供商抽象」给出的统一请求形状与能力声明(参数面板要照它渲染)。原型作为资产链接到本 ticket。

## Answer

**决策(2026-07-16 拍板):采用 Layout 1 双栏控制台。** 详见 [ui-prototype.md](../assets/ui-prototype.md)。

- 会话中渲染了两版可交互 mockup 对比:Layout 2(对话流)vs Layout 1(双栏控制台)→ **选 Layout 1**。
- **左栏控制台**:Mode 分段(文生图 / 参考图)→ Model 选择器 → 能力提示 → 提示词 → 参考图上传(仅参考图模式)→ **动态参数面板** → 成本预估「≈$」→ 生成按钮。**右栏**:大图预览 + 本批缩略条 + 结果元信息 + 操作(下载 / 重生 / 存模板 / 删除)。**图库**走顶栏 tab。
- **动态参数面板**验证了 03 的核心:OpenAI 出「尺寸 / 质量 / n」、Gemini 出「宽高比 / 分辨率、n=1」,全由 `capabilities` / `pricing` 元数据驱动;成本预估、参考图上限同步随模型变。
- Prompt Template 入口在提示词框旁;成本三处呈现(生成前预估 / 结果实际 / 图库累计,见 07)。

**这是地图的最后一个 ticket** —— 七个决策全部就位,通往目的地的路已清晰。
